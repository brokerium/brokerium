# Brand

The Brokerium mark shows three brokers of equal height inside a ring, with a partition being
placed above them: a balanced cluster. The name and the mark are trademarks of Bulat Valiev; see
[TRADEMARKS.md](../../TRADEMARKS.md) for how others may use them.

| [brokerium-mark.svg](brokerium-mark.svg) | The mark, for light and dark backgrounds; also the dashboard favicon |
| [brokerium-mark-white.svg](brokerium-mark-white.svg) | One-color mark on dark or colored backgrounds |

converted to outlines, so the files render the same everywhere without fonts.

## Colors

| Role | Value |
| --- | --- |
| Gradient start (indigo) | `#4C6EF5` |
| Gradient end (violet) | `#7950F2` |
| Partition tint | `#91A7FF` |
| Ink (text on light) | `#1A1B1E` |
| Paper (text on dark) | `#F8F9FA` |

The gradient runs from the top left to the bottom right. The dashboard uses the same indigo as
its primary color.

## Rules

- Keep clear space around the mark of at least a quarter of its height.
- Smallest size: 16 px for the mark, 24 px height for the logo with the name.
- Do not stretch, rotate, recolor (other than the files above), add effects, or place the mark
  on busy photos.
- Never combine the mark with the Apache Kafka logo; write "Brokerium for Apache Kafka" in text
  and keep the ASF attribution where Apache Kafka is mentioned.
