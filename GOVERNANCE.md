# Governance

## Decision making

Brokerium is a single-maintainer project. Bulat Valiev ("the maintainer") owns the
project, sets the roadmap and makes final decisions on features, architecture,
releases and licensing.

- Ideas, bug reports and feature requests are collected in GitHub issues and
  discussions. Anyone can propose; the maintainer decides what is built.
- Only the maintainer has write access to the repository and merges pull requests.
- Architectural decisions are recorded in [docs/adr/](docs/adr/).
- The public roadmap lives in [docs/ROADMAP.md](docs/ROADMAP.md) and the GitHub
  project "Brokerium Roadmap".

## Licensing policy

- Brokerium is source-available under the PolyForm Shield License 1.0.0.
- Future versions may be published under different license terms, for example a more
  permissive license or an additional commercial edition.
- Versions that are already published always keep the license they were published
  with. A license change never applies retroactively.
- Features that are free in a published version are not moved behind a paywall in
  later versions.
- All external contributions are accepted under the [CLA](CLA.md), which allows the
  project to make these decisions.

## Releases

Releases follow semantic versioning. Before version 1.0.0, minor versions may contain
breaking changes; they are described in [CHANGELOG.md](CHANGELOG.md).

## Succession

If the project or its intellectual property is transferred to a company or a new
owner, that owner takes over the maintainer role, the trademarks and all rights
granted under the CLA. The transfer is announced in the repository.
